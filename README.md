# С днём рождения, бабушка!

Мобильная открытка с семейными фотографиями, объёмной галереей при прокрутке и поздравлением.

Статический сайт без сборки и внешних зависимостей. Фотографии находятся в `photos/`, оформление и текст - в `index.html`.

Локальный запуск: `python -m http.server 4173`.

GitHub Pages: публикация из корня ветки `main`.

Сайт: https://TeemFlash.github.io/gra/
